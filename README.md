# multisig-station-streamline-releases

精简多签站（`multisig-station-streamline`）**在线更新**发布仓。

- 清单：本仓 `main/latest.json`
- 安装包：本仓 GitHub Releases 附件 `streamline-VERSION.zip`
- 业务源码仓：https://github.com/e12games/multisig-station-streamline

站点 `.env` 配置示例：

```
UPDATE_RELEASES_URL=https://raw.githubusercontent.com/e12games/multisig-station-streamline-releases/main/latest.json
```
